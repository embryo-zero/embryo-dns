# Embryo DNS

Embryo DNS is Embryo-Zero's fork of [pdns](https://github.com/PowerDNS/pdns) (c3fda64, commit c3fda64). It does authoritative DNS server.

- Our changes live on the `embryo` branch. The original license files (COPYING, NOTICE) are unchanged.
